# 產品需求文件 (PRD)

**專案名稱：** 智慧衣櫥 (Smart Closet)
**專案描述：** 一個結合天氣與行程的智慧衣櫥系統，能自動推薦每日穿搭，並具備溫濕度監控與自動殺菌除濕功能，以節省出門準備時間並保持衣物最佳狀態。

## 1. 專案概述

### 背景與動機
每天早上常在衣櫥前猶豫不決，不知道該穿什麼。為了節省每天挑選衣物的時間，並確保衣物在潮濕環境中不易發霉或產生異味，我們希望設計一款「智慧衣櫥」，透過自動化的衣物管理、穿搭推薦及環境控制，讓使用者出門前能更有效率，甚至能多睡幾分鐘。

### 目標用戶
- 有選擇障礙、不知道如何穿搭的人
- 生活忙碌、沒有時間整理衣物或思考穿搭的人（例如：大學生、上班族等）

### 核心價值主張
- **節省時間：** 結合外部資訊自動推薦穿搭，縮短出門前的準備時間。
- **自動化保養：** 自動偵測環境並啟動除濕與殺菌，保持衣物乾燥與衛生。
- **智慧化管理：** 整合個人行程與天氣資訊，提供最合適的服裝建議。

---

## 2. 功能需求

### F-01 穿搭推薦系統
- 作為 **使用者**，我希望 **系統能根據當天天氣或我的行程推薦穿搭並顯示在魔鏡上**，以便 **我不用花時間煩惱要穿什麼**。

### F-02 衣物管理系統
- 作為 **使用者**，我希望 **系統能記錄我擁有的衣物種類與數量**，以便 **我能清楚掌握自己的衣櫃狀態**。

### F-03 自動除濕與殺菌控制
- 作為 **使用者**，我希望 **衣櫥能在濕度過高時自動開啟除濕，並定時進行 UVC 殺菌**，以便 **我的衣服不會發霉或產生異味**。

### F-04 天氣與行程整合
- 作為 **系統**，我希望 **能自動串接氣象 API 與使用者的行事曆**，以便 **為穿搭推薦提供準確的參考數據**。

### F-05 即時狀態顯示
- 作為 **使用者**，我希望 **能在魔鏡螢幕上看到當前的衣櫥溫濕度與殺菌燈狀態**，以便 **隨時了解衣櫥的運作情況**。

### F-06 手動與自動模式切換
- 作為 **使用者**，我希望 **可以透過魔鏡介面手動強制啟動除濕或殺菌功能**，以便 **在必要時進行額外的衣物保養**。

---

## 3. 非功能需求

### 技術限制
- **前端技術：** HTML / CSS / JavaScript（魔鏡介面）
- **後端技術：** Python + Flask
- **硬體整合：** 溫濕度感測器 (DHT11/22)、UVC 殺菌燈等

### 效能考量
- **回應速度：** 穿搭推薦的生成時間需控制在 3~5 秒內，避免使用者在魔鏡前等待過久。

### 安全考量
- **硬體防護：** UVC 殺菌燈必須具備安全機制，當衣櫥門被打開時，殺菌燈必須自動關閉，以防紫外線對人體（眼睛、皮膚）造成傷害。
- **使用介面：** 魔鏡使用大字與高對比呈現，確保在沒戴眼鏡的情況下也能看清楚。

---

## 4. MVP 範圍

### Must Have (必須具備)
- 魔鏡介面即時顯示溫濕度資訊 (F-05)
- 基本的衣物記錄與管理功能 (F-02)
- 溫濕度感測與手動/自動除濕功能 (F-03, F-06)

### Should Have (應該具備)
- 串接天氣 API 的基礎穿搭推薦 (F-01, F-04)
- 自動 UVC 殺菌與開門斷電安全保護機制 (F-03, 安全考量)

### Nice to Have (最好具備)
- 結合個人行程（行事曆）的進階穿搭推薦 (F-04)

*(備註：自動摺衣服與自動洗衣服功能明確列為 Out of Scope)*

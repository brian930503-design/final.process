# 智能衣櫃管理系統 - Product Requirements Document (PRD)

## 1. 專案概述

### 背景與動機
現代人常面臨「衣服很多卻不知道穿什麼」、「常忘記自己有哪些衣服」或「找不到特定衣服」的困擾，甚至常因此重複購買相似的衣物。為了解決這些痛點，我們希望能打造一個「智能衣櫃管理系統」，幫助使用者將實體衣櫃數位化，隨時隨地掌握衣物狀況，並提供智能穿搭建議。

### 目標用戶
- 衣服數量較多，需要系統化管理的使用者。
- 注重個人形象與日常穿搭，但希望節省出門前挑選衣服時間的上班族或學生。
- 想要改善購物習慣，減少衝動消費的人。

### 核心價值主張
- **省時**：快速瀏覽所有衣物，並透過智能建議減少搭配時間。
- **省錢**：清楚掌握現有衣物，避免重複購買相似款式。
- **條理**：透過標籤與分類，讓個人物品管理井然有序。

---

## 2. 功能需求

### 1. 衣物建檔與管理
- 作為 **使用者**，我希望 **能上傳衣物照片並標註屬性（如：顏色、季節、場合、品牌）**，以便 **將實體衣物數位化，方便隨時檢視與管理**。

### 2. 智能穿搭建議
- 作為 **使用者**，我希望 **系統能根據今日天氣資訊與我選擇的場合，自動推薦適合的穿搭組合**，以便 **節省我每天早上煩惱穿什麼的時間**。

### 3. 自訂穿搭組合（虛擬試衣間）
- 作為 **使用者**，我希望 **能在系統上自由挑選並組合不同的上衣、下著與配件，並儲存起來**，以便 **在不實際換衣服的情況下預覽搭配效果，並在未來快速套用**。

### 4. 衣物使用與清洗追蹤
- 作為 **使用者**，我希望 **能記錄每件衣服的穿著次數與上次清洗時間，並接收清洗提醒**，以便 **保持衣物的清潔與延長使用壽命**。

### 5. 衣櫥數據統計與分析
- 作為 **使用者**，我希望 **能看到衣櫃的統計數據（如：最常穿/最少穿的衣服、顏色比例）**，以便 **更了解自己的穿衣習慣，並在未來購物時作為參考，減少不必要的花費**。

---

## 3. 非功能需求

### 技術限制
- 後端框架：Flask
- 模板引擎：Jinja2
- 資料庫：SQLite

### 效能與安全考量
- **效能**：
  - 圖片上傳時需進行自動壓縮，以節省伺服器儲存空間並提升圖片載入速度。
  - 系統頁面載入時間（尤其是衣物總覽列表）需控制在 2 秒以內。
- **安全性**：
  - 需實作基本的使用者註冊與登入機制（如密碼雜湊加密），確保每個人的衣櫃資料為私人擁有，防止未授權存取。
  - 防範常見的網頁攻擊（如 SQL Injection, XSS 等）。

## 4. MVP 範圍 (Minimum Viable Product)

| 優先級 | 功能項目 |
| :--- | :--- |
| **Must Have**<br>(必須擁有) | 1. 使用者註冊與登入功能<br>2. 衣物上傳與建檔（圖片、名稱、分類）<br>3. 衣物總覽列表與單件詳細檢視<br>4. 基礎穿搭組合的建立與儲存 |
| **Should Have**<br>(應該擁有) | 1. 根據天氣或場合自動推薦穿搭<br>2. 衣物條件搜尋與進階過濾（依顏色、季節） |
| **Nice to Have**<br>(有會更好) | 1. 衣物統計分析圖表（最常穿、顏色分佈）<br>2. 穿衣次數追蹤與清洗提醒<br>3. 支援一鍵分享穿搭組合至社群平台 |
